# iwebcam iOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the iwebcam iOS app: capture the phone's camera, pair with a
client over a QR code, and stream H.264 video over WiFi via a custom TCP
protocol.

**Architecture:** A SwiftUI app with no third-party dependencies. Six
isolated services (QR payload, NAL framing, handshake, pairing/IP
resolution, QR image rendering, TCP server) are pure/testable in CI.
`CameraCaptureService` and `H264Encoder` depend on real hardware and are
verified manually on-device. `StreamingCoordinator` wires everything
together behind an `ObservableObject` that `ContentView` renders.

**Tech Stack:** Swift 5, SwiftUI, AVFoundation, VideoToolbox,
Network.framework, CoreImage. Project generated by XcodeGen (`project.yml`)
— no `.xcodeproj` is committed. Built and tested exclusively on GitHub
Actions `macos-14` runners.

**Spec:** `docs/superpowers/specs/2026-09-16-iwebcam-ios-design.md`

## Global Constraints

- No Swift/Xcode toolchain exists locally (development machine is Windows).
  **Every task's verification happens on GitHub Actions**, not locally.
- Repo: `https://github.com/LucasEzequielSilva/iwebcam` (private), remote
  `origin` already configured in `D:\Dev\iwebcam`.
- Verification command for every task, run after committing:
  `git push && gh run watch --exit-status`. This blocks until the latest
  GitHub Actions run finishes and exits non-zero if it failed — treat that
  as an unambiguous fail signal, same as a local test failure.
- Because a full CI round-trip costs real time (and macOS runner minutes are
  metered even on personal accounts), tasks do **not** do a separate
  red-CI-run / green-CI-run cycle per task like typical local TDD. Write the
  test first as specified in each task (it documents intent and catches
  copy-paste mistakes on read-through), then commit test + implementation
  together and push once, verifying green. Exception: Task 0 pushes a
  trivial failing-by-construction-then-fixed sequence isn't done either —
  Task 0 establishes the skeleton directly.
- No third-party dependencies (SPM/CocoaPods) — Apple frameworks only, per
  `.claude/stack.md`.
- Deployment target: iOS 17.0. Bundle id prefix: `com.lucas.iwebcam`.
- `CameraCaptureService` and `H264Encoder`'s hardware-dependent behavior
  (real camera frames, real hardware encoder on a physical device) cannot be
  verified in CI or in the iOS Simulator. Those tasks are marked
  **manual verification required** — CI only confirms the code compiles
  (and, for `H264Encoder`, that a synthetic in-memory frame round-trips
  through the encoder on the macOS-14/Apple-Silicon simulator).
- Installing a build on Lucas's physical iPhone (TestFlight / ad-hoc /
  signed archive) requires an Apple Developer account and code signing set
  up in CI — **out of scope for this plan**, tracked separately.

```swift
import Foundation

struct QRPayload: Codable, Equatable {
    let ip: String
    let port: UInt16
    let token: String

    func encoded() throws -> String {
        let data = try JSONEncoder().encode(self)
        guard let json = String(data: data, encoding: .utf8) else {
            throw QRPayloadError.encodingFailed
        }
        return json
    }

    static func decode(from json: String) throws -> QRPayload {
        guard let data = json.data(using: .utf8) else {
            throw QRPayloadError.decodingFailed
        }
        return try JSONDecoder().decode(QRPayload.self, from: data)
    }
}

enum QRPayloadError: Error, Equatable {
    case encodingFailed
    case decodingFailed
}
```

```swift
import Foundation

enum NALFraming {
    static func frame(_ payload: Data) -> Data {
        var framed = Data()
        var length = UInt32(payload.count).bigEndian
        withUnsafeBytes(of: &length) { framed.append(contentsOf: $0) }
        framed.append(payload)
        return framed
    }

    static func readLength(fromHeader header: Data) -> UInt32? {
        guard header.count == 4 else { return nil }
        let rawValue = header.withUnsafeBytes { $0.load(as: UInt32.self) }
        return UInt32(bigEndian: rawValue)
    }
}
```

```swift
import Foundation

protocol LocalIPProviding {
    func currentWiFiIPAddress() -> String?
}

struct SystemLocalIPProvider: LocalIPProviding {
    func currentWiFiIPAddress() -> String? {
        var address: String?
        var ifaddrPtr: UnsafeMutablePointer<ifaddrs>?
        guard getifaddrs(&ifaddrPtr) == 0, let firstAddr = ifaddrPtr else { return nil }
        defer { freeifaddrs(ifaddrPtr) }

        for ptr in sequence(first: firstAddr, next: { $0.pointee.ifa_next }) {
            let interface = ptr.pointee
            guard interface.ifa_addr.pointee.sa_family == UInt8(AF_INET) else { continue }
            guard String(cString: interface.ifa_name) == "en0" else { continue }

            var hostname = [CChar](repeating: 0, count: Int(NI_MAXHOST))
            getnameinfo(
                interface.ifa_addr, socklen_t(interface.ifa_addr.pointee.sa_len),
                &hostname, socklen_t(hostname.count), nil, 0, NI_NUMERICHOST
            )
            address = String(cString: hostname)
        }
        return address
    }
}

final class PairingService {
    let port: UInt16
    private(set) var currentToken: String = ""
    private let ipProvider: LocalIPProviding

    init(port: UInt16, ipProvider: LocalIPProviding = SystemLocalIPProvider()) {
        self.port = port
        self.ipProvider = ipProvider
    }

    @discardableResult
    func regenerateToken() -> String {
        currentToken = UUID().uuidString
        return currentToken
    }

    func buildQRPayload() -> QRPayload? {
        guard let ip = ipProvider.currentWiFiIPAddress() else { return nil }
        if currentToken.isEmpty { regenerateToken() }
        return QRPayload(ip: ip, port: port, token: currentToken)
    }
}
```

- [ ] **Step 2: Write the implementation**

```swift
import Foundation
import Network

protocol StreamServerDelegate: AnyObject {
    func streamServerDidConnect(_ server: StreamServer)
    func streamServerDidDisconnect(_ server: StreamServer)
}

enum StreamServerError: Error {
    case malformedFrame
}

final class StreamServer {
    weak var delegate: StreamServerDelegate?

    private let port: NWEndpoint.Port
    private var expectedToken: String
    private var listener: NWListener?
    private var activeConnection: NWConnection?

    init(port: UInt16, expectedToken: String) {
        self.port = NWEndpoint.Port(rawValue: port)!
        self.expectedToken = expectedToken
    }

    func updateExpectedToken(_ token: String) {
        expectedToken = token
    }

    func start() throws {
        let listener = try NWListener(using: .tcp, on: port)
        listener.newConnectionHandler = { [weak self] connection in
            self?.handleIncoming(connection)
        }
        listener.start(queue: .main)
        self.listener = listener
    }

    func stop() {
        activeConnection?.cancel()
        activeConnection = nil
        listener?.cancel()
        listener = nil
    }

    func send(frame data: Data) {
        guard let connection = activeConnection else { return }
        connection.send(content: NALFraming.frame(data), completion: .contentProcessed { _ in })
    }

    private func handleIncoming(_ connection: NWConnection) {
        guard activeConnection == nil else {
            connection.cancel()
            return
        }
        connection.start(queue: .main)
        readToken(on: connection)
    }

    private func readToken(on connection: NWConnection) {
        readFrame(on: connection) { [weak self] result in
            guard let self else { return }
            switch result {
            case .success(let tokenData):
                if StreamHandshake.isValid(receivedToken: tokenData, expectedToken: self.expectedToken) {
                    self.activeConnection = connection
                    self.delegate?.streamServerDidConnect(self)
                    self.monitorDisconnection(on: connection)
                } else {
                    connection.cancel()
                }
            case .failure:
                connection.cancel()
            }
        }
    }

    private func monitorDisconnection(on connection: NWConnection) {
        connection.stateUpdateHandler = { [weak self] state in
            guard let self else { return }
            switch state {
            case .cancelled, .failed:
                if self.activeConnection === connection {
                    self.activeConnection = nil
                    self.delegate?.streamServerDidDisconnect(self)
                }
            default:
                break
            }
        }
    }

    private func readFrame(on connection: NWConnection, completion: @escaping (Result<Data, Error>) -> Void) {
        connection.receive(minimumIncompleteLength: 4, maximumLength: 4) { header, _, _, error in
            if let error {
                completion(.failure(error))
                return
            }
            guard let header, let length = NALFraming.readLength(fromHeader: header) else {
                completion(.failure(StreamServerError.malformedFrame))
                return
            }
            connection.receive(minimumIncompleteLength: Int(length), maximumLength: Int(length)) { payload, _, _, error in
                if let error {
                    completion(.failure(error))
                    return
                }
                guard let payload else {
                    completion(.failure(StreamServerError.malformedFrame))
                    return
                }
                completion(.success(payload))
            }
        }
    }
}
```

```swift
import Foundation
import VideoToolbox
import CoreMedia

enum H264EncoderError: Error {
    case sessionCreationFailed(OSStatus)
}

protocol H264EncoderDelegate: AnyObject {
    func h264Encoder(_ encoder: H264Encoder, didProduceParameterSets sps: Data, pps: Data)
    func h264Encoder(_ encoder: H264Encoder, didEncode nalUnit: Data)
}

final class H264Encoder {
    weak var delegate: H264EncoderDelegate?

    private var session: VTCompressionSession?
    private var sentParameterSets = false
    private let width: Int32
    private let height: Int32
    private let bitrate: Int32

    init(width: Int32, height: Int32, bitrate: Int32 = 2_000_000) {
        self.width = width
        self.height = height
        self.bitrate = bitrate
    }

    func start() throws {
        var newSession: VTCompressionSession?
        let status = VTCompressionSessionCreate(
            allocator: nil,
            width: width,
            height: height,
            codecType: kCMVideoCodecType_H264,
            encoderSpecification: nil,
            imageBufferAttributes: nil,
            compressedDataAllocator: nil,
            outputCallback: nil,
            refcon: nil,
            compressionSessionOut: &newSession
        )
        guard status == noErr, let session = newSession else {
            throw H264EncoderError.sessionCreationFailed(status)
        }
        VTSessionSetProperty(session, key: kVTCompressionPropertyKey_RealTime, value: kCFBooleanTrue)
        VTSessionSetProperty(session, key: kVTCompressionPropertyKey_ProfileLevel, value: kVTProfileLevel_H264_Baseline_AutoLevel)
        VTSessionSetProperty(session, key: kVTCompressionPropertyKey_AverageBitRate, value: NSNumber(value: bitrate))
        VTSessionSetProperty(session, key: kVTCompressionPropertyKey_MaxKeyFrameInterval, value: NSNumber(value: 60))
        VTCompressionSessionPrepareToEncodeFrames(session)
        self.session = session
        sentParameterSets = false
    }

    func stop() {
        guard let session else { return }
        VTCompressionSessionInvalidate(session)
        self.session = nil
    }

    func encode(_ sampleBuffer: CMSampleBuffer) {
        guard let session, let imageBuffer = CMSampleBufferGetImageBuffer(sampleBuffer) else { return }
        let presentationTimeStamp = CMSampleBufferGetPresentationTimeStamp(sampleBuffer)
        VTCompressionSessionEncodeFrame(
            session,
            imageBuffer: imageBuffer,
            presentationTimeStamp: presentationTimeStamp,
            duration: .invalid,
            frameProperties: nil,
            infoFlagsOut: nil
        ) { [weak self] status, _, sampleBufferOut in
            guard status == noErr, let sampleBufferOut else { return }
            self?.handleEncodedSampleBuffer(sampleBufferOut)
        }
    }

    private func handleEncodedSampleBuffer(_ sampleBuffer: CMSampleBuffer) {
        if !sentParameterSets, let formatDescription = CMSampleBufferGetFormatDescription(sampleBuffer),
           let sets = Self.extractParameterSets(from: formatDescription) {
            delegate?.h264Encoder(self, didProduceParameterSets: Self.annexB(sets.sps), pps: Self.annexB(sets.pps))
            sentParameterSets = true
        }
        guard let dataBuffer = CMSampleBufferGetDataBuffer(sampleBuffer),
              let annexBData = Self.convertAVCCToAnnexB(dataBuffer) else { return }
        delegate?.h264Encoder(self, didEncode: annexBData)
    }

    private static func annexB(_ nalPayload: Data) -> Data {
        Data([0x00, 0x00, 0x00, 0x01]) + nalPayload
    }

    private static func convertAVCCToAnnexB(_ blockBuffer: CMBlockBuffer) -> Data? {
        var length = 0
        var dataPointer: UnsafeMutablePointer<Int8>?
        guard CMBlockBufferGetDataPointer(blockBuffer, atOffset: 0, lengthAtOffsetOut: nil, totalLengthOut: &length, dataPointerOut: &dataPointer) == noErr,
              let dataPointer else { return nil }

        var result = Data()
        var offset = 0
        let startCode = Data([0x00, 0x00, 0x00, 0x01])
        let buffer = UnsafeRawBufferPointer(start: dataPointer, count: length)

        while offset + 4 <= length {
            let nalLength = Int(buffer[offset]) << 24 | Int(buffer[offset + 1]) << 16 | Int(buffer[offset + 2]) << 8 | Int(buffer[offset + 3])
            offset += 4
            guard offset + nalLength <= length else { break }
            result.append(startCode)
            result.append(Data(bytes: dataPointer + offset, count: nalLength))
            offset += nalLength
        }
        return result
    }

    private static func extractParameterSets(from formatDescription: CMFormatDescription) -> (sps: Data, pps: Data)? {
        var spsPointer: UnsafePointer<UInt8>?
        var spsLength = 0
        var ppsPointer: UnsafePointer<UInt8>?
        var ppsLength = 0
        var setCount = 0

        guard CMVideoFormatDescriptionGetH264ParameterSetAtIndex(
            formatDescription, parameterSetIndex: 0, parameterSetPointerOut: &spsPointer,
            parameterSetSizeOut: &spsLength, parameterSetCountOut: &setCount, nalUnitHeaderLengthOut: nil
        ) == noErr, setCount >= 2 else { return nil }

        guard CMVideoFormatDescriptionGetH264ParameterSetAtIndex(
            formatDescription, parameterSetIndex: 1, parameterSetPointerOut: &ppsPointer,
            parameterSetSizeOut: &ppsLength, parameterSetCountOut: nil, nalUnitHeaderLengthOut: nil
        ) == noErr, let spsPointer, let ppsPointer else { return nil }

        return (Data(bytes: spsPointer, count: spsLength), Data(bytes: ppsPointer, count: ppsLength))
    }
}
```

```swift
final class CameraCaptureService: NSObject {
    weak var delegate: CameraCaptureServiceDelegate?

    private let session = AVCaptureSession()
    private let output = AVCaptureVideoDataOutput()
    private let queue = DispatchQueue(label: "com.lucas.iwebcam.camera")

    var previewLayer: AVCaptureVideoPreviewLayer {
        AVCaptureVideoPreviewLayer(session: session)
    }

    func requestPermissionAndStart(position: AVCaptureDevice.Position = .back, completion: @escaping (Result<Void, Error>) -> Void) {
        switch AVCaptureDevice.authorizationStatus(for: .video) {
        case .authorized:
            configureAndStart(position: position, completion: completion)
        case .notDetermined:
            AVCaptureDevice.requestAccess(for: .video) { [weak self] granted in
                DispatchQueue.main.async {
                    guard granted else {
                        completion(.failure(CameraCaptureError.permissionDenied))
                        return
                    }
                    self?.configureAndStart(position: position, completion: completion)
                }
            }
        default:
            completion(.failure(CameraCaptureError.permissionDenied))
        }
    }

    func stop() {
        queue.async { [weak self] in
            self?.session.stopRunning()
        }
    }

    private func configureAndStart(position: AVCaptureDevice.Position, completion: @escaping (Result<Void, Error>) -> Void) {
        session.beginConfiguration()
        session.sessionPreset = .hd1280x720

        guard let device = AVCaptureDevice.default(.builtInWideAngleCamera, for: .video, position: position),
              let input = try? AVCaptureDeviceInput(device: device),
              session.canAddInput(input) else {
            session.commitConfiguration()
            completion(.failure(CameraCaptureError.deviceUnavailable))
            return
        }
        session.addInput(input)

        output.setSampleBufferDelegate(self, queue: queue)
        guard session.canAddOutput(output) else {
            session.commitConfiguration()
            completion(.failure(CameraCaptureError.deviceUnavailable))
            return
        }
        session.addOutput(output)
        session.commitConfiguration()

        queue.async { [weak self] in
            self?.session.startRunning()
        }
        completion(.success(()))
    }
}

    func captureOutput(_ output: AVCaptureOutput, didOutput sampleBuffer: CMSampleBuffer, from connection: AVCaptureConnection) {
```

### Task 11: Python test client (dev tool)

**Files:**

**Interfaces:**
- Consumes the wire protocol produced by `StreamServer`/`H264Encoder`:
  `[4-byte big-endian length][token]` handshake, then
  `[4-byte big-endian length][Annex-B parameter sets]` once, then a stream
  of `[4-byte big-endian length][Annex-B NAL unit]` frames.

- [ ] **Step 1: Write the script**

```python
#!/usr/bin/env python3
"""Minimal client to validate the iwebcam stream end to end.

Usage: python stream_client.py <ip> <port> <token>
Performs the handshake, receives the Annex-B H.264 stream, and pipes it
to ffplay. Requires ffplay (part of ffmpeg) on PATH.
"""
import socket
import struct
import subprocess
import sys


def send_framed(sock: socket.socket, payload: bytes) -> None:
    sock.sendall(struct.pack(">I", len(payload)) + payload)


def recv_exact(sock: socket.socket, size: int) -> bytes:
    buffer = b""
    while len(buffer) < size:
        chunk = sock.recv(size - len(buffer))
        if not chunk:
            raise ConnectionError("conexión cerrada por el servidor")
        buffer += chunk
    return buffer


def read_framed(sock: socket.socket) -> bytes:
    header = recv_exact(sock, 4)
    (length,) = struct.unpack(">I", header)
    return recv_exact(sock, length)


def main() -> None:
    if len(sys.argv) != 4:
        print("Uso: python stream_client.py <ip> <port> <token>")
        sys.exit(1)

    ip, port, token = sys.argv[1], int(sys.argv[2]), sys.argv[3]

    ffplay = subprocess.Popen(["ffplay", "-f", "h264", "-i", "-"], stdin=subprocess.PIPE)

    with socket.create_connection((ip, port)) as sock:
        send_framed(sock, token.encode("utf-8"))
        parameter_sets = read_framed(sock)
        ffplay.stdin.write(parameter_sets)
        ffplay.stdin.flush()
        while True:
            nal_unit = read_framed(sock)
            ffplay.stdin.write(nal_unit)
            ffplay.stdin.flush()


if __name__ == "__main__":
    main()
```
